help_outline 如何阅读结果与测试标准

请注意，本测试中显示的【基础协议通过】仅代表该端点正确响应了 Anthropic Messages API 的 HTTP 状态码与 SSE 块协议规范，绝不代表其数据传输没有被监听、记录，亦不能证明其底层真实调用的是 Anthropic 官方模型正品。

• 探针请求载荷: 统一 1,024 字符基准 prompt
• 协议严格度: 包含 content_block_start / delta / stop 顺序校验
fingerprint 【身份存疑】判定原理

我们部署了基于特定数学难题与逆向推理的探针问卷。当请求端点声称返回的是 gpt-6.1-luna，但其输出特征、Token 概率熵值或推理步骤模式与低阶模型（如 Haiku、开源模型蒸馏体）高度吻合时，探针将触发指纹异常审计，并在多次复现后打上该标记。

policy 【完全中立承诺】

本站绝不收录任何推广返佣链接 (No AFF)，不设任何形式的付费置顶广告，不接受服务商资金赞助以影响指标权重。所有排序与评分均基于探针抓包指标全自动计算。
